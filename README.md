# Homie

Главный экран (лаунчер) для приставок на Android TV: простой, крупный и настраиваемый с пульта.
Без рекламы, без интернета, без сбора данных.

## Что умеет

- **Ряды приложений.** Первый ряд — «док» на матовой подложке, ниже свои ряды
  («Телевидение», «Кино», «Детям»…) и «Остальные приложения». Новые приложения появляются сами.
- **Всё настраивается пультом.** Удерживайте ОК на плитке (или нажмите «Меню»): переставить
  стрелками, перенести в другой ряд, убрать с главного экрана, скрыть.
- **Размер.** Плитки — от маленьких до очень крупных, надписи — обычные, крупные, очень крупные.
- **Два стиля.** Современный — ряды плиток; Классика — карусель обложек с отражением
  на глянцевом полу и выпуклыми стеклянными кнопками.
- **Оформление в духе Apple TV.** Без рамок: выбранное белое и приподнято с мягкой тенью,
  плавный подъём, лёгкий наклон и блик; шрифт Inter.
- **Фон.** Фотографии природы (меняются каждые 10 минут) или одна из галереи, тёмный или синий.
- **Кнопки состояния.** Сеть (Wi-Fi с силой сигнала, кабель или «нет сети»), питание
  (сон, перезагрузка), настройки.
- **Автозапуск.** Можно выбрать приложение, которое откроется само после включения приставки.

## Установка

1. Установите APK из раздела Releases.
2. Нажмите «Домой» на пульте и выберите Homie (или в настройках приставки:
   Приложения → Приложения по умолчанию → Главный экран).
3. Для кнопки питания один раз включите Homie в
   Настройки → Специальные возможности. Служба только выполняет «сон» и «меню питания»
   и ничего на экране не читает.

Через ADB:

```
adb install homie-<версия>.apk
adb shell cmd package set-home-activity ru.iptvsimple.home/.MainActivity
```

## Сборка

Нужны JDK 17 и Android SDK (platform 37).

```
./gradlew :app:assembleRelease
```
